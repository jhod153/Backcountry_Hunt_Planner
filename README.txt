BACKCOUNTRY HUNT PLANNER - FULL PROTOTYPE

This package contains the full mobile web app with 143 food library entries.

To use on an iPhone:
1. Host the contents of this folder on a simple static web host.
2. Open the hosted URL in Safari.
3. Tap Share > Add to Home Screen.

To test on a computer:
1. Unzip this package.
2. In the folder run: python3 -m http.server 8000
3. Open http://localhost:8000

The approved Food layout is preserved:
- Breakfast, Lunch, Dinner, Snacks, Treats, Electrolytes, Emergency Food
- Selected foods visible and editable
- +/- quantity controls
- Searchable fully populated dropdown per meal section
- Day copy + templates
- Nutrition and weight recalculation

Latest pack changes are included:
- Hilleberg/Cimarron mutually exclusive
- optional pack liner, Tyvek, rain jacket/pants
- optional Nalgene, hydration bladder, Jetboil
- bear spray optional with small/large size
- Bic lighter primary fire starter
- wax cubes quantity based
- fuel size and quantity
- squeeze bags, dry bags, game bags, AAA batteries quantity based


GEAR LIBRARY ARCHITECTURE UPDATE
- Master Gear Library: 137 starter products across 7 major backcountry hunting brands.
- My Gear: current personal gear plus products added from the library.
- Pack: remains organized by carrying/packing categories; product choices feed into pack weight.
- Unverified library weights are visibly flagged and require a measured weight before they can replace a pack item.
- Custom gear can be added directly to My Gear.
